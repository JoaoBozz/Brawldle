# 🎯 Brawldle

**Brawldle** é um jogo web de dedução inspirado em *Wordle*, *Pokedle* e *Loldle*, ambientado no universo de **Brawl Stars**.

O objetivo é simples: **descobrir o brawler correto usando lógica, comparação e eliminação**, com base em feedbacks fornecidos a cada tentativa.

O projeto foi pensado para ser **rápido de entender**, **difícil de dominar** e **viciante a longo prazo**.

---

## 🧠 Conceito do Jogo

A cada partida, o jogador deve adivinhar um brawler secreto.  
Após cada tentativa, o jogo fornece feedback visual indicando quais características estão corretas, incorretas ou parcialmente corretas.

O foco do Brawldle não é memória pura, mas **raciocínio dedutivo**.

Exemplos de atributos analisados:
- Classe do brawler  
- Raridade  
- Tipo de ataque  
- Alcance  
- Mobilidade  
- Outros atributos relevantes do jogo  

Com base nessas informações, o jogador ajusta sua próxima hipótese até encontrar a resposta correta.
